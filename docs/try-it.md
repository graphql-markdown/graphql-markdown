# Try it

Live demos and sandboxes for each supported framework. Open one to see the generated output, or fork it to try your own schema.

## Docusaurus

See the generated docs in the [live demo](https://graphql-markdown.dev/demo-docusaurus/).

Use the [CodeSandbox template](https://codesandbox.io/p/sandbox/github/graphql-markdown/demo-docusaurus/tree/main?file=/.graphqlrc) or fork our [demo repo](https://github.com/graphql-markdown/demo-docusaurus) to try with your own GraphQL schema.

Edit the configuration in `.graphqlrc`.

## Astro/Starlight

See the generated docs in the [live demo](https://graphql-markdown.dev/demo-astro-starlight/).

Use the [CodeSandbox template](https://codesandbox.io/p/sandbox/github/graphql-markdown/demo-astro-starlight/tree/main?file=/graphql.config.mjs) or fork our [demo repo](https://github.com/graphql-markdown/demo-astro-starlight) to try with your own GraphQL schema.

Edit the configuration in `graphql.config.mjs`.

## Astro/Starlight on Cloudflare R2

See the generated docs in the [live demo](https://demo-astro-r2.edno.workers.dev/).

Fork our [demo repo](https://github.com/graphql-markdown/demo-astro-r2) to see the [`outputAdapter`](/docs/reference/settings#outputadapter) setting write the generated docs straight into a Cloudflare R2 bucket. It runs locally with Wrangler's R2 emulation, no Cloudflare account needed.

Edit the configuration in `graphql.config.ts`.
